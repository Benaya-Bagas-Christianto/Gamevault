# Redesign Layout ala Epic Games Store

Mohon maaf atas kesalahpahaman sebelumnya! Berdasarkan gambar Epic Games Store yang Anda lampirkan, saya mengerti sekarang. Anda menginginkan layout modern dengan tata letak seperti ini:

## Proposed Changes

### 1. Navigasi Sidebar Kiri (Left Sidebar)
- Memindahkan menu utama (**Toko**, **Library**, **Bantuan**) dari atas (Header) atau tempat lain menjadi sebuah **Sidebar Statis di sebelah Kiri**, persis seperti di Epic Games.

### 2. Desain Baru Hero Carousel (Epic Style)
- Carousel utama (Hero) tidak lagi menggunakan titik-titik (dots) kecil di bawahnya.
- **Kiri (Utama):** Akan menampilkan *cover* game yang sedang aktif dengan ukuran besar, teks judul, deskripsi, dan tombol aksi (Beli/Gratis).
- **Kanan (Daftar/Thumbnail):** Di dalam area Carousel tersebut, pada sisi kanannya akan ada daftar vertikal game-game yang masuk ke dalam Carousel (sebagai tombol navigasi).
- Ketika Anda mengklik salah satu *thumbnail* di sebelah kanan, gambar besar di sebelah kirinya akan berubah sesuai game yang diklik (persis seperti navigasi *Discover* di Epic Games).

## User Review Required

Perubahan ini cukup besar karena mengubah struktur navigasi utama (menambahkan Sidebar Kiri) dan merombak total tampilan Carousel utama. 
1. Apakah Anda setuju menu **Toko, Library, Bantuan** dipindah ke Sidebar Kiri permanen?
2. Apakah bentuk desain Carousel dengan Thumbnail di Kanan ini yang Anda bayangkan?

Jika Anda setuju, saya akan langsung memulai perombakan struktur halamannya!
